## C1. Witness sharing across quadratics (a)
SoS-collapse soundness is UNAFFECTED by sharing: Σ Q_i² = 0 ⟺ every Q_i = 0, whatever pool the
witnesses come from. Sharing only risks the (⇒) direction: a shared witness must satisfy all
quadratics it enters SIMULTANEOUSLY; independent residuals with independent witness maps become
jointly unsatisfiable. Decision procedure (mechanical): compute each residual's witness map
w_i = f_i(q) (M7); build a compatibility graph (edge iff f_i ≡ f_j as polynomials or the maps
agree on the intended q-fibre); share within cliques only. If the line is pattern-generated,
the maps agree per pattern class — sharing collapses each class to one witness pool.
Δvars: up to −(N − #pattern-classes). Δdeg: 0. Δterms: ~0.

## C2. Definable-witness inlining (M4/M7 applied to the line)
Any residual whose private witness is FORCED (w = f(q) polynomial) under the witness map can be
substituted out: the quadratic stays quadratic iff f is linear (degree-neutral); a quadratic f
pushes that residual's term to degree 6 (tie-breaker hit). Line/catalogue residuals typically
have LINEAR tracks (a = αq + β or a = q·(pattern)). Δvars: −(#forced witnesses), potentially
thousands. Δterms: grows by substitution.
